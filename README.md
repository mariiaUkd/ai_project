# 🎭 AI Multi-Agent Studio

**AI Multi-Agent Studio** — це інтелектуальний веб-інструмент, призначений для генерації та професійного аналізу креативних ідей за допомогою архітектури декількох ШІ-агентів. Система імітує роботу креативного відділу, де один агент створює контент, а інший — проводить його критичний аудит.

## 🌟 Основна ідея
Проєкт вирішує проблему "кризи білого аркуша" та відсутності об'єктивної критики на ранніх етапах розробки ігор або сценаріїв. Замість одного чат-бота ви отримуєте систему з двох ролей:
1.  **Сценарист:** розробляє детальний концепт за коротким описом користувача.
2.  **Критик:** аналізує роботу сценариста, шукає слабкі місця та пропонує покращення.

## 🛠 Технологічний стек
**Frontend:** HTML, CSS (Flexbox/Grid для адаптивності).
**Backend:** JavaScript (Fetch API, Async/Await).
**AI Core:** Gemini Robotics-ER 1.6 preview.
**Networking:** Інтеграція з VPN-протоколами для подолання регіональних обмежень.

## 🚀 Функціональні можливості
**Приватність:** Поле введення API-ключа приховано (type="password") для захисту ваших даних.
**Живий статус:** Візуальні індикатори роботи кожного агента в реальному часі.
**Структурований вивід:** Результати розділені на окремі блоки для зручного читання.
**Очищення сесії:** Кнопка для швидкого скидання ідеї та результатів без видалення ключа.

## 🔧 Встановлення та запуск
1. Стягніть файли проєкту: `index.html`, `style.css`, `script.js`.
2. Отримайте API-ключ у [Google AI Studio](https://aistudio.google.com/).
3. Увімкніть **VPN** (рекомендовані локації: США або країни ЄС).
4. Переконайтеся, що в налаштуваннях браузера або розширення VPN дозволено доступ до **"URL-адрес файлів"**.
5. Відкрийте `index.html` та почніть розробку!

## 🛡 Вирішення технічних проблем (QA)
В процесі розробки було успішно подолано:
**Помилка 400 (Location not supported):** Вирішено через VPN та налаштування доступу до файлових шляхів.
**Помилка 429 (Too many requests):** Реалізовано систему обробки квот та інформування користувача.
**CORS Issues:** Налаштовано коректну передачу заголовків запиту до серверів Google.
